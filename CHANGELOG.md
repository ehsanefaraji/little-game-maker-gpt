# Changelog

## 3.1.0+11
- Added a high-resolution 4×3 custom fox hero sprite sheet with idle, run, and jump animation rows.
- Added animated forest slime enemy and gold coin sprite sheets.

- Kept the existing alternative character sprite sheets and Forge2D collision geometry.
