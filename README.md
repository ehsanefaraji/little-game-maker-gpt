# بازی‌ساز کوچولو | Little Game Maker

یک بازی‌ساز فارسی و آفلاین با Flutter برای طراحی، ویرایش و اجرای بازی‌های کودکانه؛ همراه با موتور Flame/Forge2D برای سکوبازی فیزیکی، Sprite Sheet، ویرایشگر چندلایه، پروژه‌های چندمرحله‌ای و پشتیبان‌گیری قابل‌انتقال.

## امکانات فعلی

- **هزارتو:** تولید مرحله تصادفی با مسیر قابل‌حل، دیوار، گوهر، نقطه شروع و خروجی؛ بررسی بازبودن مسیر پیش از اجرای پیش‌نمایش.
- **سکوبازی:** موتور Flame و Forge2D با گرانش و برخورد واقعی، حرکت پیوسته، پرش و پرش دوم، سکوهای فیزیکی، دوربین دنبال‌کننده، دشمن، سکه، جان و نقطه پایان.
- **رانندگی:** سه مسیر، تغییر لاین، موانع متحرک، جایزه‌های قابل‌جمع‌آوری و امتیاز.
- ویرایشگر لمسی با انتخاب ابزار و کشیدن ابزار روی خانه‌ها؛ همراه با واگرد/انجام دوباره تا ۸۰ تغییر و پاک‌کردن سریع صفحه. سکوبازی از پنج لایه مستقل (لایه اصلی، پس‌زمینه، زمین و سکو، اشیا و جایزه‌ها، شخصیت‌ها و دشمنان) پشتیبانی می‌کند؛ لایه‌ها برای هر مرحله جداگانه ذخیره می‌شوند.
- ساخت حداکثر ۲۰ مرحله برای هر پروژه، جابه‌جایی میان مراحل، تکثیر و حذف مرحله؛ پس از پایان هر مرحله می‌توان به مرحله بعد رفت.
- پشتیبان‌گیری و انتقال پروژه‌ها با خروجی JSON در کلیپ‌بورد و واردکردن JSON در دستگاه دیگر.
- تصویرسازی برداری اختصاصی برای شخصیت‌ها، موانع، سکه‌ها، گوهرها، سکوها و خودرو؛ بدون وابستگی به ایموجی دستگاه یا دریافت تصویر از اینترنت. هشت شخصیت انتخابی سکوبازی با Sprite Sheet اختصاصی چهار فریمی برای حالت ایستادن، دویدن و پریدن متحرک می‌شوند.
- پس‌زمینه‌های نقاشی‌شده با Canvas، انتخاب شخصیت و چهار تم رنگی، صدا و موسیقی تولیدشده درون برنامه. صفحه اصلی نیز بنر داستانی اختصاصی، روباه وکتور، کارت‌های بازی گرادیانی و کارت‌های پروژه بازطراحی‌شده دارد.
- ذخیره و ویرایش پروژه‌ها روی دستگاه با `shared_preferences`؛ اجرای بازی‌ها بدون اینترنت.
- نرمال‌سازی داده‌های ذخیره‌شده قدیمی یا ناقص برای جلوگیری از خراب‌شدن پروژه‌ها؛ پروژه‌های تک‌مرحله‌ای قدیمی به‌صورت خودکار به قالب چندمرحله‌ای تبدیل می‌شوند.

## اجرای پروژه در محیط توسعه

نسخهٔ پایدار Flutter همراه با Dart 3.12 یا جدیدتر و Android SDK/NDK را نصب کن، سپس در ریشه پروژه اجرا کن:

```bash
flutter create . --platforms=android --org com.littlegamemaker --project-name little_game_maker
flutter pub get
flutter test
flutter analyze
flutter run
```

دستور `flutter create` پوشه‌های پلتفرم اندروید را برای این سورس تولید می‌کند؛ این پوشه‌ها در ZIP سورس نگهداری نشده‌اند و Workflow گیت‌هاب نیز همین کار را پیش از ساخت انجام می‌دهد.

## ساخت APK امضاشده با GitHub Actions

Workflow با نام **Android Release APK** در این مسیر قرار دارد:

`.github/workflows/android-release.yml`

Workflow با هر Push به شاخه `main` و همچنین با اجرای دستی (`workflow_dispatch`) اجرا می‌شود. دو Repository Secret را در مسیر **Settings → Secrets and variables → Actions → New repository secret** ثبت کن. مقدار هر Secret متن کامل فایل هم‌نام آن در بستهٔ خصوصی امضاست:

- `LITTLEGAMEMAKER_KEYSTORE_BASE64`
- `LITTLEGAMEMAKER_STORE_PASSWORD`

بستهٔ خصوصی، فایل `.p12` و متن Secretها را در Git بارگذاری نکن. کلید این بسته از نوع PKCS12 با alias ثابت `little-game-maker` است. در صورت استفاده از کلید فعلی برنامه برای به‌روزرسانی، همین alias و رمز یکسان برای کلید و مخزن لازم است؛ تنظیمات Workflow را در صورت نیاز با کلید فعلی هماهنگ کن.

محتویات ZIP سورس (از جمله پوشهٔ مخفی `.github`) باید در ریشهٔ شاخهٔ `main` باشند. اگر اولین Push قبل از ثبت Secrets انجام شده، بعد از ثبت آن‌ها از **Actions → Android Release APK → Run workflow** ساخت را دوباره اجرا کن.

پس از موفقیت Workflow، فایل APK را از بخش **Actions → اجرای موفق → Artifacts → little-game-maker-release-apk** دریافت کن.

## نکات انتشار

- برای انتشار به‌روزرسانی، `version` در `pubspec.yaml` را افزایش بده؛ قالب آن `version: major.minor.patch+buildNumber` است.
- برای انتشار عمومی، کلید امضای ثابت و امن خودت را نگه دار و در نسخه‌های بعدی از همان کلید استفاده کن؛ تغییر کلید ممکن است مانع نصب به‌روزرسانی روی نسخه قبلی شود.
- این مخزن شامل سورس است و فایل APK در زمان اجرای Workflow ساخته می‌شود.

## قابلیت‌های نسخه 3.1.0+11

- **موتور سکوبازی:** Flame 1.38.2 و flame_forge2d 0.20.0؛ Forge2D برای شبیه‌سازی گرانش، جسم پویا، برخورد با سکوها و دیواره‌ها.
- **فیزیک بازیکن:** حرکت پیوسته با شتاب متفاوت روی زمین و هوا، پرش دوم، پرش بافرشده و coyote-time برای پاسخ‌گویی بهتر کنترل لمسی، محدودیت محیط و بازگشت پس از برخورد با دشمن یا سقوط.
- **انیمیشن:** فایل `assets/images/fox_animations.png` شامل هشت مجموعه شخصیت است؛ هر مجموعه سه ردیف (ایستادن، دویدن و پرش) و هر ردیف چهار فریم دارد.
- **لایه‌ها:** هر مرحله می‌تواند حداکثر پنج لایه مستقل داشته باشد. لایه‌های بالاتر روی لایه‌های زیرین قرار می‌گیرند؛ پاک‌کن در لایه بالاتر می‌تواند محتوای زیرین را در همان خانه پنهان کند.
- **سازگاری:** پروژه‌های نسخه‌های قبلی هنگام خواندن به ساختار یک‌لایه‌ای تبدیل می‌شوند و می‌توانند در نسخه جدید ویرایش شوند.
- **وابستگی‌ها:** Flame و Forge2D برای اجرای سکوبازی استفاده می‌شوند؛ هزارتو و رانندگی همچنان از پیاده‌سازی فعلی Flutter استفاده می‌کنند.

## نکات فنی و محدودیت‌ها

- موتور فیزیک Forge2D در حال حاضر برای بازی سکوبازی به کار رفته است؛ هزارتو و رانندگی هنوز موتورهای اختصاصی سبک خود را دارند.
- انیمیشن Sprite Sheet فعلی برای شخصیت روباه است. برای شخصیت‌های دیگر باید Sprite Sheetهای متناظر به کتابخانه دارایی افزوده شوند.
- ویرایشگر چندلایه فعلاً برای سکوبازی فعال است؛ ترتیب لایه‌ها ثابت است و پنل تغییر ترتیب آزاد یا مخفی/نمایان‌کردن لایه‌ها در این نسخه وجود ندارد.
- داده‌های قدیمی با نوع «memory» هنگام واردسازی به قالب هزارتو تبدیل می‌شوند تا برنامه با پروژه‌های قدیمی از کار نیفتد.
- تست‌ها و ساخت APK باید در محیط دارای Flutter سازگار با Dart 3.12+ و Android SDK/NDK اجرا شوند. محیط تولید این بسته Flutter SDK نداشت؛ بنابراین اجرای واقعی `flutter test`, `flutter analyze` و `flutter build apk` در اینجا تأیید نشده است.


## Premium Adventure Art Pack (3.1.0)

The platformer now bundles a dedicated 4×3 fox hero animation sheet (idle, run, jump), a four-frame animated forest slime, a four-frame animated gold coin, and an illustrated adventure tile atlas. The premium fox is selected when the fox character is chosen; other character choices retain their existing sprite animations. Flame animates collectibles and enemies in real time, with subtle squash-and-stretch motion. The world backdrop also includes a distant castle, floating grass islands, waterfall accents, and ambient sparkle particles.
